  scale_fill_manual(values = c("blue", "purple", "red"))
Code
# What facet_wrap do does it separate each of the historical data into different parts, in this case three seperate density graphs.

  geom_density() +
  scale_fill_manual(values = c("blue", "purple", "red")) +
  facet_wrap(~historical)
Code
# This density plot would not be useful to track data because the graph is telling us that it alignes with all the repub_pct_20 data.
